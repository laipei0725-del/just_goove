## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion browser ensure
npx remotion render src/index.ts JustGrooveLogo out/just-groove-logo.mp4
```

Composition 為 704×396、30fps、45 frames（1.5 秒），包含 Logo 彈跳、Y2K 網格、發光模糊與淡出。

**Upgrade Remotion**

```console
npx remotion upgrade
```
